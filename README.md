# 🏡 Barn House Portfolio Website

A clean, modern, and responsive portfolio website that showcases barn house architecture and interior design services with a blend of rustic charm and modern aesthetics.

---

## 🌟 Project Overview

This project is a beautifully designed barn house portfolio site featuring:

- Rustic wood and modern metal blend visuals
- Service categories like Commercial & Residential
- Real-time stats & client achievements
- Smooth user experience with thoughtful layout
- Portfolio gallery with details view
- Contact form to discuss upcoming projects

---

## 🧱 Sections Included

- ✅ Navbar
- ✅ Hero Banner
- ✅ Introductory Section (We design thoughtful, liveable spaces)
- ✅ Service Categories (Commercial & Residential)
- ✅ Statistics Counter (Clients, Departments, Staffs, etc.)
- ✅ Our Work Process (Concept, Design, Supervision, Budget)
- ✅ Latest Portfolio Gallery
- ✅ Project Discussion Form (Contact)
- ✅ Footer

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
